\section*{\textcolor{blauPista}{Qüestió 2}}

\noindent Considereu el sistema d'equacions següent, on $m$ és un paràmetre real:
\[
\left.\begin{array}{r}
x - 3y + mz = -2 \\
x + my + 2z = 3 \\
x + y + 2z = m
\end{array}\right\}
\]

\subsection*{\textit{a)} \normalfont Discutiu el sistema segons el valor del paràmetre $m$. \hfill\textnormal{[1,25 punts]}}

\pista{Escriu la matriu de coeficients $A$ i la matriu ampliada $A^{'}$. Calcula $\det(A)$ i troba els valors del paràmetre $m$ que l'anul·len. Per a cadascun d'aquests valors, compara els rangs de $A$ i $A^{'}$.}

\subsection*{\textit{b)} \normalfont Trobeu la solució del sistema per a $m = 0$. \hfill\textnormal{[0,5 punts]}}

\pista{Substitueix $m = 0$. Comprova si aquest valor està entre els que has trobat a l'apartat anterior, és a dir, els valors que anul·laven el determinant. Per exemple, si $m=0$ no forma part dels valors trobats a l'apartat anterior, vol dir que el sistema serà compatible determinat i, per tant, trobaràs una solució numèrica i serà única.}

\subsection*{\textit{c)} \normalfont Per a $m = 2$, doneu una solució $(x, y, z)$ del sistema que, a més a més, compleixi $x = 5y$. \hfill\textnormal{[0,75 punts]}}

\pista{Per a $m = 2$, veuràs que el sistema és compatible indeterminat. La manera de procedir pot ser aquesta: en primer lloc, pots "alliberar" una variable, perquè precisament tens un grau de llibertat. Per exemple, $z = \lambda$). En una segon pas, has d'expressar $x$ i $y$ en funció de $\lambda$, a partir de les equacions. Finalment, afegeix l'equació extra de l'enunciat $x = 5y$. Obtindràs equacions amb $\lambda$, però amb aquesta darrera equació, podràs resoldre-ho tot i trobaràs els valors concrets numèrics de $x$, $y$ i $z$.}
